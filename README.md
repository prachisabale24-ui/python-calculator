# Python Calculator 🧮

A simple calculator application built using Python. This project performs basic mathematical operations and handles invalid inputs.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Repeats calculations until the user exits
- Handles invalid number inputs
- Prevents division by zero
- Validates menu choices

## Technologies Used
- Python

## Concepts Used
- Variables and data types
- `if-elif-else` statements
- `while` loop
- `try-except` error handling
- User input and output

## How to Run
1. Download the Python file from this repository.
2. Make sure Python is installed on your computer.
3. Open the terminal in the folder containing the file.
4. Run the command:

   `python "calculator .py"`

5. Choose an operation from the menu.
6. Enter two numbers and view the result.
7. Select option 5 to exit.
